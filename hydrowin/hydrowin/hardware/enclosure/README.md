**КОМПАС по функциям (рекомендуется):** [KOMPAS_BY_FUNCTIONS.md](KOMPAS_BY_FUNCTIONS.md) — Эскиз, Вырезать, Присоединить…

**Импорт STL:** [KOMPAS_ASSEMBLY.md](KOMPAS_ASSEMBLY.md).

Параметрическая модель в **OpenSCAD** с кабельными каналами (вычитание объёмов).

## Файлы

| Файл | Назначение |
|---|---|
| `hydrowin_enclosure.scad` | Корпус, отверстия, жалюзи |
| `cable_routing.scad` | Канавки, карманы, keepout-зоны |
| `hydrowin_shell.stl` | Оболочка (без стоек) |
| `hydrowin_standoffs_board.stl` | Стойки ESP32 |
| `hydrowin_standoffs_dcdc.stl` | Стойки DC-DC |
| `hydrowin_base.stl` | Полная сборка для печати |
| `hydrowin_lid.stl` | Крышка |

## Габариты

| Параметр | Значение |
|---|---|
| Внутренняя длина | **150 мм** (плата LilyGO 110 мм + запас) |
| Внутренняя ширина × высота | 72 × 42 мм |
| PG7 | **Ø12.8 мм**, ось Z = плоскость канавок |
| Площадка PG7 | R ≥ 10 мм без канавок на стенке |

## Кабельные каналы (вычитание)

| Линия | Ширина × глубина | Примечание |
|---|---|---|
| Питание 24V (PG7→предохранитель→DC-DC) | 2.6 × 3.0 мм | OD провода 2.5 мм |
| Карман предохранителя | 42 × 14 × 26 мм | под корпус 40×13×25 |
| 5V (DC-DC→ESP32) | 2.3 × 2.5 мм | OD 2.2 мм |
| Сигнальные ×6 | 1.5 × 1.8 мм, шаг 3.0 мм | к GPIO |
| Карман резистора | 8 × 3 × 3 мм | на каждой линии |
| BNC | 3.0 × 3.2 мм | к разъёмам |
| Скругление поворотов | R ≥ 4.0 мм | |
| Keepout у крепежа | ≥ 1.5 мм | стойки, BNC |

## Вентиляция DC-DC

Жалюзи в полу над DC-DC: ламели **1.5 мм**, зазор **2.0 мм**, угол **45°**.

## КОМПАС-3D

Подробная пошаговая инструкция: **[KOMPAS_ASSEMBLY.md](KOMPAS_ASSEMBLY.md)**

Кратко: создайте **сборку**, импортируйте STL **по отдельности** (`shell`, `standoffs_*`, `lid`). Для печати без разборки — один файл `hydrowin_base.stl`.

```powershell
cd hydrowin\hardware\enclosure
.\export-stl.ps1
```

См. [POWER_WIRING.md](../../firmware/POWER_WIRING.md).
