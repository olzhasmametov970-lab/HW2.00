# HydroWin — КОМПАС-3D по функциям

Инструкция по **операциям КОМПАС**: какая функция → что нажать → какие цифры ввести.

Две детали: **низ** (`hydrowin_base.m3d`) и **крышка** (`hydrowin_lid.m3d`).

---

## Быстрая шпаргалка размеров

| Что | Размер |
|---|---|
| Внешний корпус | 155.6 × 77.6 × 44.8 мм |
| Полость внутри | 150 × 72 × 42 мм |
| Стенка / дно | 2.8 мм |
| LilyGO | 110×34, стойки h=10 |
| DC-DC | 66×27, стойки h=4 |
| PG7 | Ø12.8 |
| BNC ×6 | Ø14, шаг 17.5 |
| Саморез крышки | Ø3.4 в крышке, пилот Ø2.3 в низе |

# ДЕТАЛЬ 1 — НИЗ КОРПУСА

## Функция 1: Создать деталь

```
Файл → Создать → Деталь
Файл → Сохранить как → hydrowin_base.m3d
```

---

## Функция 2: Эскиз (контур)

**Где:** плоскость **XY** (дно, Z=0).

```
Оформление → Эскиз
  (или: Эскиз → Создать эскиз на плоскости XY)
```

**Что нарисовать:**

| Инструмент | Действие |
|---|---|
| Прямоугольник | 155.6 × 77.6 мм, угол в (0, 0) |
| Размеры | Привязать к началу координат |

```
Эскиз → Завершить создание эскиза
```

---

## Функция 3: Тонкостенный элемент (корпус-оболочка)

```
Операции → Тонкостенный элемент → Выдавить
```

| Поле | Значение |
|---|---|
| Эскиз | только что созданный |
| Высота | **44.8** мм |
| Толщина стенки | **2.8** мм |
| Направление толщины | **внутрь** |

**Результат:** полость 150×72×42 мм.

> **Нет «тонкостенного»?**  
> Выдавливание дна 2.8 мм → на верхней грани эскиз 150×72 со смещением 2.8 → выдавить стенки 42 мм.

---

## Функция 4: Эскиз на плоскости стенки

Повторяется для каждого отверстия в стенке.

### 4а. PG7 — левая стенка (−X)

```
Эскиз → Плоскость грани левой стенки
```

| Параметр | Значение |
|---|---|
| Круг | **Ø12.8** |
| Центр Y | **20.3** |
| Центр Z | **4.55** |

### 4б. USB — левая стенка

| Параметр | Значение |
|---|---|
| Прямоугольник | **10 × 4** мм |
| Центр Y | **56.8** |
| Центр Z | **18.8** |

### 4в. BNC ×6 — задняя стенка (+Y)

| Параметр | Значение |
|---|---|
| Круг | **Ø14** |
| Z центра | **14.8** |
| X центров | 34.05 · 51.55 · 69.05 · 86.55 · 104.05 · 121.55 |

### 4г. SMA ×2 — задняя стенка

| Параметр | Значение |
|---|---|
| Круг | **Ø6.6** |
| Z | **34.8** |
| X | **30.8** и **124.8** |

---

## Функция 5: Выдавливание → Вырезать (сквозные отверстия)

После каждого эскиза на стенке:

```
Операции → Эскивание → Вырезать
```

| Поле | Значение |
|---|---|
| Глубина | **Сквозное** (через всю стенку) |
| Направление | перпендикулярно стенке |

Повторить для PG7, USB, 6× BNC, 2× SMA.

---

## Функция 6: Массив (копии BNC без ручного копирования)

Если рисовали **один** BNC:

```
Операции → Массив → Линейный массив
```

| Поле | Значение |
|---|---|
| Объект | вырез BNC |
| Направление | ось **X** |
| Количество | **6** |
| Шаг | **17.5** мм |
| Смещение первого | X = **34.05** |

> Или 6 отдельных эскизов по таблице X — надёжнее.

## Функция 7: Эскиз + Выдавливание → Присоединить (стойки)

**Плоскость:** дно полости (Z = 2.8).

### 7а. Стойки DC-DC (4 шт.)

```
Эскиз → 4 круга Ø6.5
```

| № | X | Y |
|---|---|---|
| 1 | 48.8 | 10.8 |
| 2 | 106.8 | 10.8 |
| 3 | 48.8 | 29.8 |
| 4 | 106.8 | 29.8 |

*(глоб. = внутр. + 2.8)*

```
Операции → Выдавливание → Присоединить
  Высота: 4 мм
  Направление: +Z
```

### 7б. Стойки LilyGO (4 шт.)

Те же операции, круги **Ø6.5**:

| № | X (глоб.) | Y (глоб.) |
|---|---|---|
| 1 | 26.8 | 43.8 |
| 2 | 128.8 | 43.8 |
| 3 | 26.8 | 69.8 |
| 4 | 128.8 | 69.8 |

```
Выдавливание → Присоединить
  Высота: 10 мм
```

## Функция 8: Выдавливание → Вырезать (отверстия M3 в стойках)

На верхней грани каждой стойки (или один эскиз со всеми 8 центрами):

```
Эскиз → 8 кругов Ø3.2 в центрах стоек
Операции → Выдавливание → Вырезать → Сквозное
```

---

## Функция 9: Эскиз + Вырезать (канавки в дне)

**Плоскость:** внутреннее дно полости (Z = 2.8).

Канавка = узкий прямоугольник в эскизе → вырез вниз.

### 9а. Питание 24V

| Параметр | Значение |
|---|---|
| Ширина эскиза | **2.6** мм |
| Глубина выреза | **3.0** мм |
| Трасса (центр. линия) | (13.8; 20.3) → (24.8; 20.3) → (24.8; 35) → (62.8; 33.8) |

```
Выдавливание → Вырезать
  Глубина: 3.0 мм
  Направление: −Z (в дно)
```

### 9б. Карман предохранителя

| Параметр | Значение |
|---|---|
| Прямоугольник | **14 × 42** мм |
| Позиция | X=8.8…22.8, Y≈0…42 (глоб.) |
| Глубина | **26** мм вверх (+Z) |

```
Выдавливание → Вырезать
  Направление: +Z (в полость)
```

### 9c. Линия 5V

|---|---|

## Функция 10: Скругление (Fillet) — повороты канавок

```
Операции → Сопряжение → Скругление
```

| Поле | Значение |
|---|---|
| Рёбра | внешние углы канавок на поворотах |
| Радиус | **R4** мм (минимум) |

> На эскизе канавки можно сразу рисовать с дугами R4.

## Функция 11: Эскиз + Вырезать (жалюзи DC-DC)

**Зона в полу:** X=47.8…107.8, Y=9.8…30.8 (глоб.).

```
Эскиз → несколько узких прямоугольников под углом 45°
  Толщина ламели (остаётся): 1.5 мм
  Зазор (вырезается): 2.0 мм
```

```
Выдавливание → Вырезать
  Глубина: 2.8 мм (сквозь дно) или 2.0 мм
```

*Ламели остаются — вырезаете только щели между ними.*

# Порядок операций (чеклист)

### Низ
- [ ] **1** Создать деталь
- [ ] **2–3** Эскиз + Тонкостенный элемент (корпус)

- [ ] **6** Массив BNC (опционально)

- [ ] **15–16** Деталь + пластина
- [ ] **17** Губа
- [ ] **18** Отверстия Ø3.4
- [ ] **19** Сохранить

### Сборка
- [ ] **20–22** Сборка + вставка + смещение крышки
