# HydroWin — сделать корпус с нуля (полная инструкция)

От нуля до готового напечатанного корпуса с электроникой внутри.

```
┌─────────────────────────────────────────────┐  ← крышка (4 самореза)
│  [LilyGO 110×34]          BNC×6  SMA×2     │

└─────────────────────────────────────────────┘
     ○ PG7 (24V)              USB (сервис)
```

### Программы (бесплатные)

| Программа | Зачем | Ссылка |

| **КОМПАС-3D** | Просмотр, сборка, правки (у вас уже есть) | — |

| Компонент | Размеры / тип |

| PETG или ASA | пластик для печати |

### Инструменты

- Штангенциркуль (замер отверстий на плате)
- Мультиметр
- Паяльник, провода 0.5–0.75 мм²
- Отвёртка крестовая

## Часть 1. Два пути — какой выбрать

| | **Путь A: OpenSCAD** (рекомендуется) | **Путь B: только КОМПАС** |
|---|---|---|
| Сложность | Низкая — меняете цифры в файле | Высокая — рисуете всё вручную |

| Когда брать | Почти всегда | Если нет OpenSCAD и нужна одна деталь |

**Дальше — Путь A.** В конце файла — кратко про Путь B.

## Часть 3. Открыть проект и понять структуру

Папка модели:

```
HW2.0/hydrowin/hydrowin/hardware/enclosure/
├── hydrowin_enclosure.scad   ← главные размеры корпуса
├── cable_routing.scad        ← канавки и карманы
├── hydrowin_shell.scad       ← экспорт только оболочки
├── hydrowin_base.scad        ← экспорт низа целиком
├── hydrowin_lid.scad         ← экспорт крышки
├── export-stl.ps1            ← сборка всех STL одной командой
└── KOMPAS_ASSEMBLY.md        ← импорт в КОМПАС
```

### Как устроена модель (логика)

1. **Параллелепипед** с вырезанной полостью — корпус.
2. **Вычитание** (`difference()`): отверстия BNC, PG7, USB, канавки, жалюзи.
3. **Добавление** (`union()`): стойки под платы.
4. Крышка — отдельная деталь с губой и отверстиями под саморезы.

## Часть 4. Замерьте свою плату (обязательно)

Отверстия крепления на LilyGO могут отличаться от закладки в модели.

1. Положите плату штангенциркулем.
2. Замерьте **расстояние от края PCB до центра каждого отверстия** (4 угла).
3. Откройте `hydrowin_enclosure.scad`, найдите:

```openscad
board_hole_inset = 4;  // ← подставьте свой замер
```

4. То же для DC-DC: `dcdc_hole_inset = 4;`

### Проверка посадки в OpenSCAD

В конце `hydrowin_enclosure.scad` раскомментируйте две строки:

```openscad
%translate([wall + board_x0, wall + board_y0, floor + board_standoff_h])
    cube([board_len, board_w, board_h]);
%translate([wall + dcdc_x0, wall + dcdc_y0, floor + dcdc_standoff_h])
    cube([dcdc_len, dcdc_w, dcdc_h]);
```

Нажмите **F5** (превью) или **F6** (полный рендер) — полупрозрачные блоки покажут, куда лягут платы.

## Часть 5. Собрать STL (экспорт модели)

### Способ 1 — скрипт (быстро)

```powershell
cd C:\Users\Admin2\Desktop\HW2.0\hydrowin\hydrowin\hardware\enclosure
.\export-stl.ps1
```

Появятся файлы:

| STL | Назначение |
|---|---|
| `hydrowin_shell.stl` | Корпус без стоек |
| `hydrowin_standoffs_board.stl` | Стойки ESP32 |
| `hydrowin_standoffs_dcdc.stl` | Стойки DC-DC |
| `hydrowin_base.stl` | **Низ для печати** (всё вместе) |
| `hydrowin_lid.stl` | Крышка |

### Способ 2 — вручную в OpenSCAD

1. Откройте `hydrowin_base.scad`
2. **F6** (Render) — подождите 1–2 минуты
3. **File → Export → Export as STL…** → `hydrowin_base.stl`
4. Повторите для `hydrowin_lid.scad`

## Часть 7. 3D-печать

### Что печатать

| Файл | Количество |
|---|---|
| `hydrowin_base.stl` | 1 |
| `hydrowin_lid.stl` | 1 |

### Настройки слайсера (ориентир для PETG)

| Параметр | Значение |
|---|---|
| Материал | PETG или ASA |
| Высота слоя | 0.2 мм |
| Заполнение | 20–30 % |
| Стенки | 3–4 периметра |
| Дно на столе | **Внешним дном корпуса вниз** |
| Крышка | внешней поверхностью вверх |
| Поддержки | обычно **не нужны** (канавки вверх) |
| Адгезия | brim 5–8 мм по периметру дна |

### После печати

1. Снять с стола, убрать brim.
2. Протестировать **Ø14 мм** вставку в отверстие BNC — при необходимости подогнать `bnc_hole_d` в SCAD.
3. Протестировать **Ø12.8 мм** под PG7.
4. Вкрутить BNC, SMA, сальник PG7 — проверить посадку до монтажа электроники.

## Часть 8. Сборка электроники в корпусе

Полная схема проводов: [POWER_WIRING.md](../../firmware/POWER_WIRING.md)

### Порядок монтажа

```
1. DC-DC на 4 стойки (M3)
2. Предохранитель 2–3 A в карман / на провод +24V
3. Кабель 24V через PG7 → клеммы IN DC-DC
4. LilyGO на стойки (M3, нейлоновые шайбы по желанию)
5. Провода 5V/GND: OUT DC-DC → VIN/GND платы
6. 6 линий датчиков: +24V → датчик → GPIO (CH0…CH5)
7. Коаксиал LTE/GPS: U.FL → SMA на задней стенке
8. BNC на задней стенке, сигналы к GPIO
9. Крышка на 4 самореза
```

### Куда идут провода (соответствие канавкам в модели)

| Канавка в модели | Провод |
|---|---|
| От PG7 к карману 42×14 | +24V через предохранитель |
| От кармана к DC-DC | IN+ / IN− |
| Узкая 2.3 мм к плате | 5V + GND |
| 6 линий 1.5 мм + карманы 8×3 | сигнал + резистор 150 Ω |
| Широкие 3.0 мм к BNC | выход на разъёмы |

### GPIO датчиков (T-A7670G + L76K)

| Канал | GPIO |
|---|---|
| CH0 | GPIO1 |
| CH1 | GPIO9 |
| CH2 | GPIO14 |
| CH3 | GPIO15 |
| CH4 | GPIO16 |

## Часть 9. Проверка после включения

1. БП **24 V** в PG7 или barrel DC-DC (если тест на столе).
2. Мультиметр: IN DC-DC ≈ 24 V, VIN платы ≈ 5 V.
3. USB + Serial: команда `SHOW` — токи 4–20 мА по каналам.
4. LTE и GPS регистрируются в прошивке.

## Путь B. Нарисовать корпус только в КОМПАС (без OpenSCAD)

Если хотите **полностью своими руками в КОМПАС**:

### Шаг 1. Эскиз дна

1. **Деталь → Эскиз** на плоскости XY.
2. Прямоугольник **155.6 × 77.6 мм** (150 + 2×2.8 стенки) — или сначала внутренний 150×72, потом **Операция → Выдавливание → Тонкостенный элемент**.

### Шаг 2. Полость

1. Выдавливание вверх: внутренние размеры **150 × 72 × 42 мм**.
2. Толщина стенки **2.8 мм**, дно **2.8 мм**.

### Шаг 3. Отверстия на задней стенке

- 6× круг **Ø14 мм**, шаг **17.5 мм**, центр по высоте **12 мм** от дна полости.
- 2× круг **Ø6.6 мм** (SMA), выше BNC.

### Шаг 4. PG7 на левой стенке

- Круг **Ø12.8 мм**.
- Центр по Y: зона DC-DC (передняя треть корпуса).
- Центр по Z: **~4.5 мм** от дна полости (плоскость канавок питания).
- Вокруг отверстия — гладкая зона **R10 мм** без рёбер.

### Шаг 5. Стойки

- 4 цилиндра **Ø6.5 мм**, высота **10 мм** под плату (координаты — по замеру PCB).
- 4 цилиндра высота **4 мм** под DC-DC.
- Сквозное отверстие **Ø3.2 мм** в каждой стойке.

### Шаг 6. Канавки (вычитание)

На дне полости вырежьте:

| Канавка | Ширина | Глубина |
|---|---|---|
| Питание 24V | 2.6 | 3.0 |
| 5V | 2.3 | 2.5 |
| Сигнал ×6 | 1.5 | 1.8, шаг 3.0 |
| BNC | 3.0 | 3.2 |
| Карман предохранителя | 42×14×26 | |
| Карман резистора | 8×3×3 | на каждой сигнальной линии |

Скругления поворотов **R ≥ 4 мм**.

### Шаг 7. Жалюзи под DC-DC

В полу над DC-DC: окно с ламелями **1.5 мм**, зазор **2.0 мм**, угол **45°**.

### Шаг 8. Крышка

- Пластина **155.6 × 77.6 × 3.2 мм**.
- Губа по периметру **2 мм** внутрь.
- 4 отверстия **Ø3.4 мм** в углах; в буртике низа — пилоты **Ø2.3 мм**.
