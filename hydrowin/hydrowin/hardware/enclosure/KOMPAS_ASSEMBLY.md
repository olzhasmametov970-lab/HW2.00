# Сборка корпуса HydroWin в КОМПАС-3D

Пошаговая инструкция: импорт STL, сборка, проверка посадки, подготовка к печати.

## Что понадобится

- **КОМПАС-3D** (V18 или новее; в младших версиях названия меню могут немного отличаться)
- Файлы из папки `hydrowin/hydrowin/hardware/enclosure/`:

| Файл | Для чего |
|---|---|
| `hydrowin_shell.stl` | Корпус с канавками, отверстиями, жалюзи |
| `hydrowin_standoffs_board.stl` | 4 стойки под LilyGO |
| `hydrowin_standoffs_dcdc.stl` | 4 стойки под DC-DC |
| `hydrowin_lid.stl` | Крышка |
| `hydrowin_base.stl` | *Альтернатива:* всё в одном файле (только просмотр/печать) |

---

## Вариант A — полная сборка (рекомендуется)

Отдельные детали можно двигать, скрывать и править в КОМПАС.

### Шаг 1. Новая сборка

1. Запустите КОМПАС-3D.
2. **Файл → Создать → Сборка** (или иконка «Сборка»).
3. Сохраните как `hydrowin_asm.a3d` в удобную папку.

### Шаг 2. Импорт оболочки

1. В дереве сборки: **Вставка → Деталь → Из внешнего файла…**
2. Выберите `hydrowin_shell.stl`.
3. В окне импорта:
   - Единицы: **миллиметры**
   - Тип: **Полигональный объект (STL)**
4. Нажмите **Создать** / **ОК**.
5. Деталь появится в сборке. Имя в дереве: переименуйте в `shell`.

**Ориентация:** модель из OpenSCAD уже в мм, ось Z — вверх. Если деталь «лежит на боку»:
- Выделите деталь → **Преобразования → Повернуть** (или горячие клавиши поворота).
- Поверните так, чтобы **дно корпуса** было вниз (отверстия BNC — на задней стенке сверху при виде сбоку).

### Шаг 3. Импорт стоек

Повторите **Вставка → Деталь → Из внешнего файла** для:

1. `hydrowin_standoffs_dcdc.stl` → переименуйте в `standoffs_dcdc`
2. `hydrowin_standoffs_board.stl` → переименуйте в `standoffs_board`

Стойки уже в правильных координатах относительно корпуса — **не сдвигайте**, если не подгоняете вручную.

### Шаг 4. Импорт крышки

1. Импортируйте `hydrowin_lid.stl` → `lid`.
2. Чтобы надеть крышку на корпус для проверки:
   - Выделите `lid`
   - **Преобразования → Сместить**
   - По оси **Z** сместите вверх на **~45 мм** (высота полости 42 мм + буртик; уточните по модели: верх оболочки ≈ 44.8 мм от низа)

### Шаг 5. Проверка в сборке

1. **Вид → Изометрия** — осмотрите изнутри (режим сечения или полупрозрачность).
2. Убедитесь:
   - PG7 (левая стенка, у DC-DC) — круглое отверстие Ø12.8 мм
   - 6× BNC на задней стенке
   - 2× SMA выше BNC
   - Жалюзи в полу в зоне DC-DC
   - Канавки в дне видны
3. **Измерения → Расстояние** — проверьте внутреннюю длину **150 мм**, ширину **72 мм**.

### Шаг 6. Сохранение

- **Файл → Сохранить** — сборка `hydrowin_asm.a3d`
- Каждая импортированная деталь сохранится как отдельный `.m3d` рядом со сборкой

## Вариант B — один файл (быстро, без разборки)

Подходит только для **просмотра** или **экспорта на печать** без редактирования по частям.

1. **Файл → Создать → Деталь**
2. **Вставка → Деталь → Из внешнего файла** → `hydrowin_base.stl`
3. Готово — низ с стойками и канавками в одной детали
4. Крышку импортируйте отдельно из `hydrowin_lid.stl`

---

## Как подогнать стойки под реальную плату

Если отверстия на LilyGO не совпали с моделью:

1. В сборке выделите только `standoffs_board`.
2. **Преобразования → Сместить** — сдвиньте группу стоек по X/Y на величину расхождения (замерьте штангенциркулем на плате).
3. Или отредактируйте в OpenSCAD параметр `board_hole_inset` в `hydrowin_enclosure.scad` и пересоберите STL:

```powershell
cd путь\к\hardware\enclosure
.\export-stl.ps1
```

4. В КОМПАС: удалите старую деталь стоек → импортируйте новый STL.

## Проверка посадки плат (референс-блоки)

В КОМПАС можно добавить «виртуальные» блоки габаритов:

| Компонент | Размеры (мм) | Где в модели (внутр. координаты) |
|---|---|---|
| LilyGO | 110 × 34 × 18 | X: 20…130, Y: 37…71, Z: от пола +10 |
| DC-DC | 66 × 27 × 10 | X: 42…108, Y: 4…31, Z: от пола +4 |

1. **Операции → Элементарные тела → Параллелепипед** — создайте блок нужного размера.
2. Поставьте на стойки (низ блока = высота стойки + пол).
3. Если блок пересекает стенку или канавку — подвиньте стойки или правьте OpenSCAD.

## Редактирование геометрии в КОМПАС

STL — это **сетка треугольников**, не параметрическая модель.

| Задача | Где править |
|---|---|
| Сдвинуть стойки | КОМПАС: смещение детали `standoffs_*` |
| Изменить канавки, PG7, BNC | OpenSCAD: `cable_routing.scad`, `hydrowin_enclosure.scad` → `.\export-stl.ps1` |
| Убрать/добавить отверстие | OpenSCAD или КОМПАС: **Операции → Выдавливание → Вырезать** по эскизу на грани |
| Сгладить импорт | ПКМ по STL → **Преобразовать в редактируемое тело** (если доступно в вашей версии) |

После правок в OpenSCAD в сборке: **удалите старую деталь → импортируйте новый STL** с тем же именем.

## Экспорт на 3D-печать из КОМПАС

### Печать низа целиком

1. Откройте деталь `hydrowin_base` (или сборку, оставив только shell + standoffs).
2. **Файл → Сохранить как → STL** (или экспорт в слайсер).
3. Ориентация на столе: **дном вниз** (внешнее дно корпуса на платформе).

### Печать по частям

| Деталь | Ориентация на столе |
|---|---|
| `hydrowin_shell.stl` | Дном вниз |
| `hydrowin_lid.stl` | Внешней стороной крышки вверх |
| Стойки | Плоским основанием вниз (при необходимости печатать отдельно и клеить) |

Обычно печатают **`hydrowin_base.stl` + `hydrowin_lid.stl`** — стойки уже в низе.

## Типичные проблемы

| Проблема | Решение |
|---|---|
| Деталь в метрах / огромная | При импорте STL выберите единицы **мм** |
| «Полигональный объект» не редактируется | Норма для STL; правьте в OpenSCAD или стройте эскиз поверх |
| Стойки не на месте | Смещение в сборке или `board_hole_inset` в SCAD |
| Крышка не совпадает с буртиком | Проверьте смещение по Z; верх оболочки = 42 + 2.8 мм пол |
| Канавка задевает стойку | Увеличьте `keepout_m` в `cable_routing.scad` |

## Пересборка STL после правок OpenSCAD

1. Установите [OpenSCAD](https://openscad.org/) (если ещё нет).
2. PowerShell:

```powershell
cd C:\Users\Admin2\Desktop\HW2.0\hydrowin\hydrowin\hardware\enclosure
.\export-stl.ps1
```

3. В КОМПАС обновите детали (замените файлы или переимпортируйте).

## Схема сборки

```
hydrowin_asm.a3d
├── shell              ← hydrowin_shell.stl
├── standoffs_dcdc     ← hydrowin_standoffs_dcdc.stl
├── standoffs_board    ← hydrowin_standoffs_board.stl
└── lid                ← hydrowin_lid.stl (смещён по Z вверх)
```
