# Запуск сайта ГидроВин — пошагово (домен уже есть)

Эта инструкция для ситуации: **домен куплен** (например `hydrowin.ru`), нужно выложить лендинг и научиться его обновлять через админку.

Замените `hydrowin.ru` на **ваш** домен везде, где он встречается.

---

## Что вы получите в итоге

| Адрес | Назначение |
|-------|------------|
| `https://hydrowin.ru` | Публичный лендинг |
| `https://www.hydrowin.ru` | То же (с редиректом на основной) |
| `https://hydrowin.ru/admin/` | Админка для правки текстов |

Контент сайта хранится в файле `data/content.json`. HTML вручную не трогаем.

---

## Часть 1. Подготовка на компьютере

### 1.1. Найдите папку сайта

Путь к проекту (пример):

```
C:\Users\HYDRO\.cursor\projects\...\website\
```

Внутри должны быть:

```
website/
├── index.html
├── data/content.json      ← все тексты
├── css/style.css
├── js/render.js
├── js/main.js
├── admin/                 ← админ-панель
├── assets/
└── server/                ← опционально, для сохранения с сервера
```

### 1.2. Запуск локально (проверка)

Откройте **PowerShell**:

```powershell
cd "ПУТЬ\К\ПРОЕКТУ\website"
python -m http.server 8080
```

Не закрывайте окно. В браузере откройте:

- Сайт: **http://localhost:8080**
- Админка: **http://localhost:8080/admin/**

**Что проверить:**

- [ ] Загружается главная (не «Загрузка…» бесконечно)
- [ ] Работает меню ☰ на узком экране
- [ ] В админке видны все блоки (меню, кнопки, тарифы, контакты)
- [ ] Кнопка «Скачать JSON» скачивает файл

Остановить сервер: `Ctrl+C` в PowerShell.

> **Важно:** не открывайте `index.html` двойным щелчком — через `file://` сайт не загрузит JSON.

## Часть 2. Настройка контента перед публикацией

### 2.1. Через админку (без Node.js)

1. Запустите `python -m http.server 8080` в папке `website`
2. Откройте http://localhost:8080/admin/
3. Измените тексты (email, тарифы, заголовки)
4. Нажмите **«Скачать JSON»**
5. Замените скачанный файл в `website/data/content.json`
6. Обновите страницу сайта (`F5`) — изменения видны сразу

### 2.2. Через админку с сохранением (нужен Node.js)

Установите [Node.js LTS](https://nodejs.org/) (кнопка «Download»).

```powershell
cd "ПУТЬ\К\ПРОЕКТУ\website\server"
copy .env.example .env
notepad .env
```

В `.env` задайте **свой** пароль:

```
ADMIN_PASSWORD=ваш-сложный-пароль-123
SESSION_SECRET=случайная-строка-минимум-32-символа-abcdef
PORT=8080
```

```powershell
npm install
npm start
```

- Сайт: http://localhost:8080  
- Админка: http://localhost:8080/admin/ (вход по паролю из `.env`)  
- **«Сохранить»** пишет прямо в `data/content.json`

### 2.3. Минимум перед выкладкой в интернет

- [ ] Email в блоке «Контакты» — **ваш реальный**
- [ ] Заголовок и описание (SEO) — осмысленные
- [ ] Тарифы и тексты — актуальные

## Часть 3. Публикация на Netlify + ваш домен (рекомендуется)

Самый простой путь: бесплатный HTTPS, привязка домена за 10–20 минут, обновление перетаскиванием папки.

### Шаг 1 — Регистрация

1. Откройте https://app.netlify.com  
2. **Sign up** (удобно через Google или GitHub)  
3. Войдите в аккаунт

### Шаг 2 — Первая загрузка сайта

1. На главной Netlify: **Add new site** → **Deploy manually**  
2. Откройте проводник, папку **`website`** (не весь репозиторий!)  
3. **Перетащите** папку `website` в окно браузера Netlify  
4. Дождитесь **Published** (зелёная галочка)

Временный адрес: `https://что-то-случайное.netlify.app` — откройте, убедитесь что сайт работает.

### Шаг 3 — Привязать свой домен

1. Netlify → ваш сайт → **Domain management** (или **Set up a custom domain**)  
2. **Add a domain** → введите `hydrowin.ru` → **Verify**  
3. Netlify спросит: основной домен — выберите **`hydrowin.ru`** (без www) или наоборот — как вам удобнее  
4. Добавьте также `www.hydrowin.ru` (Netlify предложит)

Netlify покажет **какие DNS-записи** нужно создать у регистратора домена.

### Шаг 4 — Настройка DNS у регистратора домена

Зайдите в панель, где покупали домен (REG.RU, Timeweb, Beget, Cloudflare и т.д.) → раздел **DNS / Управление зоной**.

#### Вариант A — через Netlify DNS (проще всего)

Netlify предложит сменить **NS-серверы** домена на свои, например:

```
dns1.p01.nsone.net
dns2.p01.nsone.net
...
```

У регистратора: **Делегирование / NS-серверы** → укажите те, что дал Netlify → сохраните.

Плюс: Netlify сам настроит всё остальное. Минус: DNS полностью у Netlify.

#### Вариант B — оставить DNS у регистратора (частый случай)

Добавьте записи **вручную** (точные значения Netlify покажет в панели; типичный пример):

| Тип | Имя (хост) | Значение |
|-----|------------|----------|
| `A` | `@` (или пусто) | IP от Netlify, напр. `75.2.60.5` |
| `CNAME` | `www` | `ваш-сайт.netlify.app` |

Для **REG.RU**:

1. Личный кабинет → **Домены** → ваш домен → **DNS-серверы и зона**  
2. Если стоят «серверы REG.RU» — откройте **Редактировать зону**  
3. Добавьте записи `A` и `CNAME` как в таблице Netlify  
4. Удалите старые конфликтующие `A` на `@`, если они ведут на парковку

Для **Timeweb**:

1. **Домены** → DNS-редактор  
2. Те же записи `A` + `CNAME`

### Шаг 5 — Дождаться и включить HTTPS

- DNS обновляется от **15 минут до 24–48 часов**  
- Netlify → Domain management → статус станет **Verified**  
- Включите **HTTPS** / **Force HTTPS** (обычно включается само)

Проверка: откройте **https://hydrowin.ru** — замок в адресной строке.

### Шаг 6 — Редирект www ↔ без www

Netlify → **Domain management** → **Options** у домена:

- Выберите **Primary domain** (например `hydrowin.ru`)  
- Второй домен (`www`) будет автоматически редиректить на основной

## Часть 4. Админка на опубликованном сайте

### Статический хостинг (Netlify, GitHub Pages, FTP)

Админка доступна по `https://hydrowin.ru/admin/`, но **без пароля** на Netlify (любой может открыть страницу).

**Как обновлять контент:**

1. Локально: `python -m http.server 8080` → правки в `/admin/`  
2. **Скачать JSON** → заменить `data/content.json` в папке `website`  
3. Снова **перетащить** папку `website` в Netlify (Deploys → drag & drop)

**Защита админки (рекомендуется):** не давайте ссылку на `/admin/` публично; для пароля нужен VPS с `website/server` (см. часть 6).

### С сервером Node.js (VPS)

На сервере с вашим доменом запускается `website/server` — тогда `/admin/` с паролем и кнопка **«Сохранить»** работает сразу. Подробнее в [DEPLOY.md](DEPLOY.md) §6.

## Часть 5. Альтернатива: хостинг REG.RU / Timeweb (FTP)

Если домен уже привязан к **виртуальному хостингу** (не Netlify):

### Шаг 1 — Найти корень сайта

В панели хостинга: **Файловый менеджер** → каталог `public_html` или `www`.

### Шаг 2 — Загрузить файлы

Загрузите **содержимое** папки `website/` **в корень** `public_html`:

```
public_html/
├── index.html          ← здесь, не в подпапке website/
├── data/content.json
├── css/
├── js/
├── admin/
└── assets/
```

Через **FileZilla** (FTP):

| Поле | Значение |
|------|----------|
| Хост | из письма хостинга (`ftp.ваш-домен.ru`) |
| Логин / пароль | из панели |
| Порт | 21 |

### Шаг 3 — SSL

В панели: **SSL** → **Let's Encrypt** → выпустить для `hydrowin.ru` и `www`.

### Шаг 4 — Проверка

Откройте `https://hydrowin.ru` и `https://hydrowin.ru/admin/`.

Обновление: замените изменённые файлы (чаще всего `data/content.json`) через FTP.

## Часть 6. Обновление сайта после запуска

| Способ хостинга | Как обновить |
|-----------------|--------------|
| Netlify (drag & drop) | Правки локально → заменить `data/content.json` → снова перетащить папку `website` |
| Netlify + Git | `git push` — деплой автоматически |
| FTP (REG.RU и т.д.) | Загрузить новый `data/content.json` (и другие изменённые файлы) |
| VPS + Node server | Правки в `/admin/` → **Сохранить** на сервере |

## Часть 8. Частые проблемы

### «Не удалось загрузить сайт» / пустая страница

- Не загружен файл `data/content.json` на хостинг  
- `index.html` лежит не в корне домена  
- Открывали через `file://` вместо сервера

### Стили «сломаны»

Проверьте, что на хостинге есть папка `css/` и путь в HTML: `css/style.css`.

### Домен не открывается после DNS

Подождите до 24–48 ч. Проверка: https://dnschecker.org — введите домен, тип `A`.

### Netlify: «DNS verification failed»

Проверьте, что старые `A`-записи на парковку удалены. Значения IP/CNAME — **точно** как в панели Netlify.

### Админка на Netlify без пароля

Это нормально для статики. Не публикуйте URL `/admin/`. Для пароля — VPS + `website/server`.

## Часть 9. Схема «домен уже есть» (кратко)

```
1. Проверить сайт локально (python -m http.server)
2. Настроить тексты в админке → content.json
3. Зарегистрироваться на Netlify
4. Перетащить папку website
5. Domain management → добавить hydrowin.ru
6. У регистратора домена → DNS (A + CNAME или NS Netlify)
7. Дождаться HTTPS
8. Открыть https://hydrowin.ru
```
