# Сайт ГидроВин



Лендинг с **админ-панелью** для редактирования всех текстов.



## Быстрый старт



**Полная инструкция с доменом:** **[LAUNCH.md](LAUNCH.md)** ← начните отсюда, если домен уже есть.



### Локально (проверка)



```powershell

cd website

python -m http.server 8080

```



| URL | Назначение |

|-----|------------|

| http://localhost:8080 | Сайт |

| http://localhost:8080/admin/ | Админка |



### С сервером и паролем (Node.js 18+)



```powershell

cd website\server

copy .env.example .env

# Смените ADMIN_PASSWORD и SESSION_SECRET в .env

npm install

npm start

```



## Админка — что можно менять



- SEO, бренд, цвет темы

- **Меню** в шапке (текст, ссылки, кнопка)

- **Главный экран**: бейдж, заголовок, кнопки, статистика, превью

- Возможности, режимы, шаги, тарифы

- Блок **«Разработчикам»** и **подвал**

- Контакты (email)



**Сохранить:** с Node-сервером — на диск; на Netlify/FTP — **Скачать JSON** → заменить `data/content.json` → перезалить сайт.



## Структура



| Путь | Назначение |

|------|------------|

| `data/content.json` | Все тексты сайта |

| `js/render.js` | Сборка страницы из JSON |

| `admin/` | Панель администратора |

| `server/` | Node.js: API, пароль, сохранение |
